Phase 2 Ring Buffer Allocator

Memory

The Problem: Memory Fragmentation

When bouncing layers between CPU and GPU, each transfer allocates new GPU memory:

Without Ring Allocator:

malloc(Layer1)
→
malloc(Layer2)
→
free(Layer1)
→
malloc(Layer3)
→ ...

Each malloc/free cycle fragments VRAM over thousands of steps.

The Solution: Pre-allocated Ring Buffer

Allocate a fixed buffer once, then slice views from it:

Core Ring Buffer Implementation

class RingBufferAllocator:
    """Pre-allocated ring buffer for layer weight transfers."""

    def __init__(self, device, target_bytes, num_cache_tensors=4):
        self.device = device
        # Split into multiple tensors to reduce fragmentation
        self.cache_tensor_size = target_bytes // num_cache_tensors
        self.cache_tensors = [None] * num_cache_tensors  # Lazy allocation

        # Ring buffer tracking
        self.allocation_start = 0  # First live byte
        self.allocation_end = 0    # Next free byte

    def allocate_like(self, source_tensor, layer_index=-1):
        """Get a view into the ring buffer matching source shape/dtype."""
        num_bytes = source_tensor.numel() * source_tensor.element_size()

        # Check for wrap-around overwrite
        if self._would_overwrite_live(num_bytes):
            return None  # Fallback to dynamic allocation

        # Slice a view from the buffer
        cache_idx = self.allocation_end // self.cache_tensor_size
        offset = self.allocation_end % self.cache_tensor_size

        byte_view = self.cache_tensors[cache_idx][offset:offset + num_bytes]
        return byte_view.view(source_tensor.dtype).view(source_tensor.shape)

The Problem: All Gradients Coexist

In standard training, the backward pass computes ALL gradients before the optimizer step:

Diagram [9]

Standard Backward: Gradients Accumulate

All ~2GB of gradients must exist simultaneously before optimizer can run

Diagram [10]

Fused Backward: Free Immediately

Only one layer's gradients exist at a time → 95% reduction in gradient memory!

Code [11]

The Magic: Post-Accumulate Gradient Hook

def attach(self):
    """Register hooks on all trainable parameters."""
    for param_group in self.optimizer.param_groups:
        for param in param_group['params']:
            if not param.requires_grad:
                continue

            # This hook fires immediately after each gradient is computed
            def hook(tensor):
                # 1. Apply gradient clipping (per-parameter)
                if self.clip_grad_norm:
                    grad_norm = tensor.grad.norm(2)
                    if grad_norm > self.clip_grad_norm:
                        tensor.grad.mul_(self.clip_grad_norm / grad_norm)

                # 2. Run optimizer step for THIS parameter only
                self._step_parameter(tensor, param_group)

                # 3. Immediately free the gradient!
                tensor.grad = None

            # PyTorch 2.0+ API for gradient hooks
            param.register_post_accumulate_grad_hook(hook)
Markdown [12]
Important Limitation: Fused backward does NOT save memory when using gradient_accumulation_steps > 1. Gradients must still accumulate across micro-batches before the optimizer step.

When to Use

Scenario Recommendation
gradient_accumulation_steps: 1 ✓ Use fused backward
gradient_accumulation_steps > 1 ✗ No memory benefit
Large batch fits in VRAM ✓ Use fused backward

Pre-computed Offload Strategy

class OffloadStrategy:
    """Pre-computes which layers to load at each step."""

    def __init__(self, layers, layer_offload_fraction):
        # Calculate byte budget for GPU
        total_bytes = sum(get_layer_bytes(l) for l in layers)
        target_loaded = int(total_bytes * (1.0 - layer_offload_fraction))

        # Pre-compute loaded sets for each scenario:
        # - Forward pass (need upcoming layers)
        # - Backward pass (need previous layers)
        # - Forward→Backward transition

        self.forward_backward_loaded = [
            self._get_optimal_layers(i, target_loaded, is_forward=True)
            for i in range(len(layers))
        ]

    def get_schedule(self, layer_index, is_forward, loaded_layers):
        """Return which layers to load/offload NOW."""
        target = set(self.forward_backward_loaded[layer_index])

        return OffloadSchedule(
            layers_to_load=sorted(target - loaded_layers),
            layers_to_offload=sorted(loaded_layers - target)
        )

Simple Bypass Logic

class SDTrainer:
    def setup_accelerate_bypass(self):
        """Detect if we can bypass Accelerate."""
        # Only bypass for single-process, no distributed plugins
        self.use_accelerate_bypass = (
            self.accelerator.num_processes == 1
            and not self.accelerator.state.deepspeed_plugin
            and not self.accelerator.state.fsdp_plugin
        )

        if self.use_accelerate_bypass:
            print("Single GPU detected: bypassing Accelerate dispatch")

    def _backward(self, loss):
        """Backward pass with optional bypass."""
        if self.use_accelerate_bypass:
            # Direct call - skip Accelerate overhead
            loss.backward()

            # Manual gradient clipping
            if self.train_config.max_grad_norm:
                torch.nn.utils.clip_grad_norm_(
                    self.params_to_optimize,
                    self.train_config.max_grad_norm
                )
        else:
            # Standard Accelerate path (multi-GPU, DeepSpeed, etc.)
            self.accelerator.backward(loss)
            if self.train_config.max_grad_norm:
                self.accelerator.clip_grad_norm_(
                    self.params_to_optimize,
                    self.train_config.max_grad_norm
                )

When Bypass is Safe

Scenario Bypass?
Single GPU, no special plugins ✓ Yes
Multi-GPU (DDP) ✗ No - need gradient sync
DeepSpeed ✗ No - DeepSpeed manages backward
FSDP ✗ No - FSDP manages sharding
Expected Speedup: 1-5% faster per step. Small but free performance — especially valuable for long training runs.
